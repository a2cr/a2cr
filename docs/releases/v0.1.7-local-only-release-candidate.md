# A2CR 0.1.7 Local-Only Release Candidate

Status: release candidate prepared locally
Date: 2026-06-25
Repository scope: `public-release/`
Tag target: `v0.1.7`

This note fixes the intended scope for the A2CR `0.1.7` local-only release
candidate. It is public-safe and contains no reviewer credentials, API keys,
local database files, local encryption keys, WorkBaton bodies, WorkStash values,
or private operational notes.

## Candidate Decision

`0.1.7` is the release candidate for the local-only public A2CR line.

The public release should present A2CR as a local MCP workspace:

- no A2CR account required;
- no API key required;
- no hosted base URL required;
- no SaaS dashboard required;
- no remote MCP connector required for normal public setup;
- WorkBaton, WorkStash, WorkThreads, actors, and events stored in the user's
  local A2CR workspace;
- browser dashboard opened through the Python CLI with `a2cr ui`;
- GitHub Release `.mcpb` asset used for the Claude Desktop Extension path until
  Anthropic Directory approval.

The legacy hosted/SaaS path is not part of the `0.1.7` public setup story.

## Release Notes Draft

Title:

```text
A2CR 0.1.7 - Local-Only Workspace
```

Body:

```text
This release moves the public A2CR distribution to a local-only workspace model.

Highlights:
- no A2CR account, API key, hosted URL, SaaS dashboard, or cloud sync required
  for normal public setup;
- `a2cr`, `a2cr-local-mcp`, and compatibility `a2cr-mcp` commands are aligned;
- local WorkBaton, WorkStash, WorkThreads, search, diagnostics, and browser UI
  are included in the Python package;
- `a2cr ui` opens a loopback-only, token-protected browser dashboard;
- Claude Desktop MCPB packaging is prepared as a GitHub Release asset for the
  local WorkBaton and WorkStash tool surface.

Install:

python -m pip install --upgrade a2cr-mcp
a2cr init codex --local
a2cr doctor --target local

Open the local dashboard:

a2cr ui

Claude Desktop users can manually install `a2cr-0.1.7.mcpb` from this GitHub
Release until Anthropic Directory approval.
```
