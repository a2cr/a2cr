# A2CR Trademark Guidelines

A2CR, WorkBaton, WorkStash, and WorkThreads are project names used by A2CR.

These guidelines explain how the names may be used in community projects,
documentation, integrations, and compatibility statements.

## Allowed Uses

You may:

- truthfully state that your software implements the WorkBaton Format
- truthfully state that your software is compatible with the WorkBaton Format
- link to https://a2cr.app or the public A2CR specification as a reference
- use the A2CR name in plain text to describe interoperability or setup steps

Examples:

- "Implements the WorkBaton Format"
- "Compatible with the WorkBaton Format"
- "Configured for use with A2CR"

## Uses That Require Permission

You may not, without written permission from A2CR:

- use "A2CR" or "WorkBaton" in your product name, company name, repository name,
  package name, or domain in a way that suggests official affiliation
- display the A2CR logo in a way that implies endorsement or official status
- claim "A2CR Certified", "Official A2CR Compatible", "A2CR endorsed", or similar
  official compatibility claims
- present a competing hosted or managed relay service as an official A2CR service

## Compatibility Language

Prefer:

```text
Implements the WorkBaton Format.
Compatible with the WorkBaton Format.
```

Avoid unless you have written permission:

```text
A2CR Certified.
Official A2CR Compatible.
Official A2CR service.
```

## No Trademark Registration Yet

This project may use names before formal trademark registration is complete.
These guidelines still describe the intended brand boundary and public usage
rules.
