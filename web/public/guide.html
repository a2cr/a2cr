A2 A2CR / Agent-to-Agent Context Relay

人間とAIエージェントのためのA2CR公開ガイド

A2CRは、Codex、Claude、CursorなどのMCP対応AIエージェントが、作業の要点を小さな WorkBatonとして保存し、別の窓・別のモデル・別のクライアントで再開するためのサービスです。

このページを読むAIエージェントへ

このHTMLはJavaScriptなしで読めます。A2CRを使う時は、HTTP APIを推測して直接呼ばず、MCPクライアントに https://a2cr.app/mcp を登録してからMCPツールを使ってください。

  • 作業が長くなる前に、save_context で要点だけを保存します。
  • 新しい窓では最初に resume_context または load_context を呼びます。
  • 保存するのは goal、current_state、next_action、必要な補足だけです。
  • APIキー、Authorizationヘッダー、DB URL、秘密情報、長いログ、全文履歴は保存しません。
  • 候補が返った場合は、推測せず返された候補から正しいSlotを選びます。

A2CRの概要

For humans

人間が管理するもの

  • GoogleログインとAPIキー発行
  • WorkBaton Slotのメタデータ確認
  • 保存数、ロード数、期限、サイズ、アクセスログの確認
  • 別AI窓に渡す保存・再開プロンプトのコピー
For agents

AIエージェントが使うもの

  • MCPの save_context で作業状態を保存
  • resume_context で新しい窓に引き継ぎ
  • list_contexts で有効なSlotを確認
  • get_account_limits で保存前に上限を確認

MCP設定方法

先にA2CRへログインし、ダッシュボードでAPIキーを発行してください。発行したキーは Authorization: Bearer <A2CR_API_KEY> としてMCPクライアントに設定します。 クライアントごとに設定ファイルの場所は変わるため、現在使っているアプリのMCP設定画面または設定ファイルに入れてください。

Codex config.toml 例

[mcp_servers."a2cr"]
url = "https://a2cr.app/mcp"

[mcp_servers."a2cr".http_headers]
Authorization = "Bearer <A2CR_API_KEY>"

Claude MCP JSON 例

{
  "mcpServers": {
    "a2cr": {
      "type": "streamable-http",
      "url": "https://a2cr.app/mcp",
      "headers": {
        "Authorization": "Bearer <A2CR_API_KEY>"
      }
    }
  }
}

Cursor MCP JSON 例

{
  "mcpServers": {
    "a2cr": {
      "type": "streamable-http",
      "url": "https://a2cr.app/mcp",
      "headers": {
        "Authorization": "Bearer <A2CR_API_KEY>"
      }
    }
  }
}

基本的な使い方

  1. 人間がA2CRにログインしてAPIキーを発行します。
  2. Codex、Claude、CursorなどのMCP設定にA2CRを追加します。
  3. AIエージェントは長い作業の途中で、要点だけをWorkBaton Slotに保存します。
  4. 新しいAI窓で同じMCP設定を使い、Slotを読み込んで続きを開始します。

AIエージェントへ渡す短い指示

A2CR service: https://a2cr.app/mcp
Use the A2CR MCP tool. Do not guess or call direct HTTP API endpoints.
Before the conversation gets long, call save_context with goal, current_state, and next_action.
Never save secrets, API keys, Authorization headers, private database URLs, full transcripts, or long logs.
In a new window, first call resume_context(slot_name="...") or resume_context(slot_number=N).
After loading, continue in the language of the current user message.

AIエージェントにとっての強み

  • チャット履歴を無理に読み返さず、MCPツールで明示的に作業状態を引き継げます。
  • next_action を保存するため、次のエージェントがすぐ作業に入れます。
  • Slotは期限付きなので、古いコンテキストが残り続けにくい設計です。
  • 人間はダッシュボードでメタデータを見られますが、通常画面では保存本文を表示しません。
  • 固定Slot番号を使えば、チームや複数AI窓で「Slot 2を読んで」のように運用できます。

English summary

A2CR is an MCP-first context relay for AI agents. It lets agents save compact WorkBaton checkpoints and resume them later from another window, model, or MCP-capable client. Register https://a2cr.app/mcp as a Streamable HTTP MCP server with Authorization: Bearer <A2CR_API_KEY>. Use MCP tools, not guessed HTTP API calls.
